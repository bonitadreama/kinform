# Roadmap

Current preview: phone-only BYOK voice, separate characters, user-confirmed memory, optional reviewable AI drafts, bounded optional history, backup/import, fixed Save controls, and editable facts.

Next priorities:

- Broader Bluetooth, lifecycle, network-loss, and key-storage device testing.
- Audit every permanently destructive action for a clear confirmation.
- Simplify settings and button organization based on real use.
- Improve clarification and language coverage without weakening candidate/confirmation boundaries.
- Decide public binary signing and update policy before distributing release APKs.

Later exploration: storage/retention controls, greeting after explicitly starting Talk, separately opt-in proactive check-ins and quiet hours, and local wake-phrase feasibility. Larger local storage does not automatically mean unlimited model recall. These are ideas, not promised features or dates.
